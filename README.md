📚 Stella Library

Stella Library adalah aplikasi perpustakaan berbasis web yang dibuat menggunakan PHP dan MySQL. Aplikasi ini dirancang untuk membantu pengelolaan data buku, anggota, dan peminjaman buku secara digital.

✨ Fitur

👤 Pengguna

- Login ke sistem.
- Melihat daftar buku.
- Mengajukan peminjaman buku.
- Melihat status peminjaman.

🛠️ Admin

- Dashboard admin.
- Mengelola data buku.
- Mengelola data anggota.
- Mengelola data peminjaman.
- Menyetujui atau menolak pengajuan peminjaman.
- Mengelola status pengembalian buku.

💻 Teknologi yang Digunakan

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap (jika digunakan dalam project)

⚙️ Cara Instalasi

1. Download atau clone repository ini.

2. Simpan folder project di dalam direktori "htdocs" pada XAMPP.

3. Jalankan Apache dan MySQL melalui XAMPP Control Panel.

4. Buka phpMyAdmin melalui "http://localhost/phpmyadmin".

5. Buat database dengan nama "perpus".

6. Import file database SQL project ke database "perpus".

7. Sesuaikan konfigurasi koneksi database dengan pengaturan MySQL lokal.

8. Buka aplikasi melalui browser:
   
   "http://localhost/Perpustakaan/"

📁 Database

Nama database: "perpus"

Database digunakan untuk menyimpan data pengguna, buku, anggota, dan transaksi peminjaman.

🎯 Tujuan Project

Project ini dibuat sebagai sarana pembelajaran dan penerapan keterampilan dalam pengembangan aplikasi web, khususnya menggunakan PHP dan MySQL.
